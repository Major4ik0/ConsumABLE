# ConsumABLE v1.3.5

**ConsumABLE** — современная система автоматизации строевого учета и формирования ежедневного расхода личного состава (строевой записки).

**Автор / Разработчик:** Журавлев Алексей

---

## Ключевые возможности

1. **Раздельный учет расхода (Общий / Мужской / Женский состав):**
   - Автоматическая детекция пола по отчеству (`-вич`, `-ич`, `-лы`, `-оглы` → Мужской; `-вна`, `-чна`, `-кызы` → Женский).
   - Быстрое ручное переключение пола (М ↔ Ж) в интерфейсе с векторными SVG-индикаторами (без эмодзи).
   - Три синхронизированные карточки статистики в реальном времени (по списку, в строю, на расходе).
   - Сквозной контроль математического баланса: `Общий = Мужчины + Женщины`.

2. **Пакетная смена курса и сдвиг (+1 курс):**
   - **Интерактивный мастер при импорте Excel:** автоопределение курса в номерах групп (например, «Обнаружен 2 курс...») и выбор актуального курса `[ 1 | 2 | 3 | 4 | 5 ]` с автоматическим обновлением 2-й цифры в кодах 4-значных групп (`1280` → `1380`).
   - **Кнопка быстрой смены курса и «+1 курс»:** мгновенный перевод всех сохраненных групп в базе в один клик.

3. **Интерактивный предпросмотр и печать (А4):**
   - Переключение срезов расхода: **«Общий расход»**, **«Парни (Мужской)»**, **«Девушки (Женский)»**.
   - Точное соответствие печати и экспорта официальному бланку (стили `@media print` для А4 portrait, разрывы страниц `page-break-inside: avoid;`, строгие границы таблиц).
   - Кнопка прямой печати `Печать (А4)` и выгрузки Excel.

4. **Экспорт отчетов в Excel (XLSX):**
   - Формирование 3 полноценных рабочих листов:
     * **«Сводный расход»**
     * **«Мужской состав»**
     * **«Женский состав»**
   - Строки раздельного расхода:
     * «Мужчины»
     * «Женщины»
     * «Всего»
   - Динамические формулы Excel (`SUM`, вычитание расхода), выравнивание подписей по центру и преднастроенные параметры страницы формата А4.

5. **Два независимых контура работы:**
   - **Desktop (PyQt5 + SQLite):** автономный офлайн-контур для рабочих станций (Windows 7/8.1/10/11 x64 и x86).
   - **Web (GitHub Pages):** клиентская веб-версия по принципу **Strict In-Memory (Zero Persistence)** — данные обрабатываются в памяти браузера без сохранения на сервере.

## Запуск приложения

### Десктопная версия (Python / PyQt5)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py
```

### Веб-версия

Откройте `web/index.html` в любом современном браузере или запустите локальный HTTP-сервер:

```bash
python -m http.server 8000 --directory web
```
