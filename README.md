# ConsumABLE v1.3.3

**ConsumABLE** — современная система автоматизации строевого учета и формирования ежедневного расхода личного состава (строевой записки).

**Автор / Разработчик:** Журавлев Алексей

---

## Ключевые возможности

1. **Раздельный учет расхода (Общий / Мужской / Женский состав):**
   - Автоматическая детекция пола по отчеству (`-вич`, `-ич`, `-лы`, `-оглы` → Мужской; `-вна`, `-чна`, `-кызы` → Женский).
   - Быстрое ручное переключение пола (М ↔ Ж) в интерфейсе с векторными SVG-индикаторами.
   - Три синхронизированные карточки статистики в реальном времени (по списку, в строю, на расходе).
   - Сквозной контроль математического баланса: `Общий = Мужчины + Женщины`.

2. **Пакетная смена курса:**
   - **Интерактивный мастер при импорте Excel:** выбор целевого курса `[ 1 | 2 | 3 | 4 | 5 ]` с автоматическим обновлением 2-й цифры в кодах 4-значных групп (например, `1280` → `1380`).
   - **Кнопка быстрой смены курса:** мгновенный перевод всех сохраненных групп в базе в один клик.

3. **Экспорт отчетов в Excel (XLSX):**
   - Формирование 3 полноценных рабочих листов:
     * **«Сводный расход»**
     * **«Мужской состав»**
     * **«Женский состав»**
   - Строки раздельного расхода в сводной таблице:
     * «Расход личного состава (Мужчины / Юноши)»
     * «Расход личного состава (Женщины / Девушки)»
     * «ИТОГО общий расход»
   - Динамические формулы Excel (`SUM`, вычитание расхода), выравнивание подписей по центру и преднастроенные параметры страницы формата А4.

4. **Два независимых контура работы:**
   - **Desktop (PyQt5 + SQLite):** автономный офлайн-контур для рабочих станций (Windows 7/8.1/10/11 x64 и x86).
   - **Web (GitHub Pages):** клиентская веб-версия по принципу **Strict In-Memory (Zero Persistence)** — данные обрабатываются в памяти браузера без сохранения на сервере.

## Запуск приложения

### Десктопная версия (Python / PyQt5)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python main.py
```

### Веб-версия

Откройте `web/index.html` в любом современном браузере или запустите локальный HTTP-сервер:

```bash
python -m http.server 8000 --directory web
```
